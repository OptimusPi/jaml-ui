# jaml-ui

Two things in the sidebar:

1. **Primitives** — `Jimbo*` controls, cards, tokens. Shown in-use, not as a sticker on felt.
2. **Apps** — the real shells.
   - **Mobile portrait** — locked 375×667 (iPhone SE CSS pixels). Width 375 is the floor.
   - **MCP on Desktop** — 375×375 host iframe. Shaped funny on purpose.
   - **Desktop Website** — full page.

`JimboApp` variants: `phone` | `embed` | `page`.
