04 Panelsreal
Two nested surfaces: outer (silver border + south-edge) and inner (deep, near-black border).
src/ui/panel.tsx · <JimboPanel> <JimboInnerPanel>

.j-panel

Top-level surface. 3px silver border, soft sheen, south-edge shadow.

.j-inner-panel

Nested surface. Inner-border fill, near-black 3px border. Hosts tiles and content.

Sway prop

JimboPanel accepts sway — adds idle tilt via useSway hook. Reserve for the topmost panel; never nest sway.

JimboPanel also accepts onBack — renders a full-width orange "Back" button at the panel's foot via .j-panel__back.

08 .j-tabsreal
Red pill buttons in a row. The active tab idle-bobs at 1px and shows a bouncing red triangle 10px above it. There is no separate "active background" state — the indicator alone is the cue.
src/ui/jimboTabs.tsx · <JimboTabs tabs activeTab onTabChange />

Hover on inactive tabs flips background to --j-dark-red. Hover on the active tab is a no-op.

13 House rules
Lifted from CLAUDE.md / AGENTS.md. Non-negotiable for any UI work in jaml-ui.
  • Never ALL CAPS. Title-case headings, sentence-case body. Letter-spacing carries emphasis.
  • Never bold. One weight only — 400. Differentiate with color or size.
  • Never grey-on-grey. Muted text on a grey surface must shift to white or a tone.
  • Mobile-first at 320px. .j-app is the default shell — fluid is opt-in.
  • Juice is CSS. Press, sway, idle-bob, font-dance, scale 1.05 are all keyframes or transitions — never JS wrappers.
  • No visible scrollbars. Hidden globally; use magnetic scroll snapping.
  • Chunky, not bubbly. Radius ≤ 10px. Buttons must have a black underside and 3px press.
  • Color carries meaning. Red = mult / destructive / boss · Blue = chips / informational · Orange = primary · Green = success / reroll · Gold = currency · Purple / Teal / Blue = tarot / planet / spectral.
