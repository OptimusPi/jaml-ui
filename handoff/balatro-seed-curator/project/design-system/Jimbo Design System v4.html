15 House rules
Lifted from CLAUDE.md / AGENTS.md. Non-negotiable.
  • Never ALL CAPS. Title-case headings, sentence-case body. Letter-spacing carries emphasis.
  • Never bold. One weight — 400. Differentiate with color or size.
  • Never grey-on-grey. Muted text on grey must shift to white or a tone.
  • Mobile-first at 320px. .j-app is the default — fluid is opt-in.
  • Juice is CSS. Press, sway, idle-bob, font-dance, scale 1.05 — all keyframes or transitions.
  • No visible scrollbars. Hidden globally; use magnetic scroll snapping.
  • Chunky, not bubbly. Radius ≤ 10. Buttons must have a black underside and 3px press.
  • Color carries meaning. Red = mult / destructive / boss · Blue = chips / info · Orange = primary · Green = success / reroll · Gold = currency · Purple / Teal / Blue = tarot / planet / spectral.
