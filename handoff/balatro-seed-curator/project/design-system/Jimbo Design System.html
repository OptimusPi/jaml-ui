12House rules Lifted from CLAUDE.md / AGENTS.md. These are non-negotiable for any UI work in jaml-ui.
  • Never ALL CAPS. Title-case headings, sentence-case body. Letter-spacing carries emphasis.
  • Never bold. One weight only. Use color or size to differentiate.
  • Never grey-on-grey. If text sits on a grey surface, it must be white or a tone color — never grey.
  • Mobile-first at 375px. All components must lay out cleanly at that width before scaling up.
  • Juice is CSS. Press, sway, font-dance, scale 1.05 — all keyframes / transitions. No JS wrappers around them.
  • No visible scrollbars. Use magnetic scroll snapping; let content imply more.
  • Chunky, not bubbly. Radius ≤ 10px. Buttons must have a black underside and a 3px press.
  • Color carries meaning. Red = mult / destructive / boss. Blue = chips / informational. Orange = primary action. Green = success / reroll. Gold = currency. Purple/teal/blue trio = tarot / planet / spectral consumables.
